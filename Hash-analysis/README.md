# Hash Analysis using hashdeep

## Overview
Hash analysis is used to verify file integrity and detect modifications.

## Tools Used
- hashdeep

## Objective
To generate and compare hash values of files.

## Procedure
1. Select a file
2. Generate hash using hashdeep
3. Modify the file
4. Recalculate hash
5. Compare results
