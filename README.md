# Cybersecurity-Attack-Simulation-Lab
## ⚠️ Disclaimer
This project was conducted in a controlled lab environment for educational purposes only.

## 📌 Project Architecture

Attacker Machine: Kali Linux  
Target Machine: Test Environment  
Tools: Wireshark, Medusa, hashdeep  

## 🧪 Lab Setup

- Virtual Machines used
- Network configuration
- Isolated environment setup

## 📊 Key Outcomes

- Identified vulnerabilities in web applications
- Demonstrated credential capture via phishing
- Performed network packet analysis
- Simulated brute-force password attacks
