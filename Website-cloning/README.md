# Website Cloning

## Overview
Website cloning involves copying a website to create a replica.

## Tools Used
- HTTrack / SET toolkit

## Objective
To replicate a website locally for phishing demonstration.

## Procedure
1. Select target website
2. Use cloning tool
3. Download website files
4. Host locally
