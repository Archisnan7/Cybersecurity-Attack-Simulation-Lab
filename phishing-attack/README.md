# Phishing Attack Simulation

## Overview
Phishing is a social engineering attack where attackers trick users into revealing sensitive information such as usernames and passwords.

## Tools Used
- Kali Linux
- Social Engineering Toolkit (SET)

## Objective
To simulate a phishing attack by creating a fake login page and capturing user credentials in a controlled lab environment.

## Procedure
1. Open SET toolkit in Kali Linux
2. Select Social Engineering Attacks → Website Attack Vectors
3. Clone a login page (e.g., Facebook/Gmail)
4. Host the phishing page
5. Share the link with a test victim (lab only)
6. Capture entered credentials

## Result
The entered credentials were successfully captured on the attacker machine.

## Learning Outcome
- Understanding phishing techniques
- Importance of user awareness
- Need for secure authentication methods

## Prevention
- Verify URLs before login
- Enable 2-factor authentication
- Avoid clicking suspicious links

## MITRE ATT&CK Mapping
- Phishing → Initial Access (T1566)
